1. CONFIGURE FIREBASE
   File: admin/js/firebase-admin.js (line ~30)
   
   Replace this:
   const firebaseConfig = {
     // Add your Firebase config here
   };
   
   With your Firebase credentials (same as in your main firestore.js):
   const firebaseConfig = {
     apiKey: "YOUR_API_KEY",
     authDomain: "YOUR_PROJECT.firebaseapp.com",
     projectId: "YOUR_PROJECT_ID",
     storageBucket: "YOUR_PROJECT.appspot.com",
     messagingSenderId: "YOUR_SENDER_ID",
     appId: "YOUR_APP_ID"
   };

2. CREATE ADMIN USER
   - Register a user on your website
   - Go to Firebase Console > Firestore > users collection
   - Find your user document
   - Add field: isAdmin = true

3. SET SECURITY RULES
   - Go to Firebase Console > Firestore > Rules
   - Copy rules from SETUP_GUIDE.md
   - Publish

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: Can't log in
Solution: 
  1. Check if user has isAdmin=true in Firestore
  2. Verify Firebase config is correct
  3. Check browser console for errors

Problem: No data showing
Solution:
  1. Verify Firebase config matches your project
  2. Check Firestore security rules
  3. Open browser console (F12) for errors

Problem: Permission denied
Solution:
  1. Set up Firestore security rules (see SETUP_GUIDE.md)
  2. Verify user is logged in
  3. Check isAdmin field is true
